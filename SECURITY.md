# Security policy

Please do not open a public issue for a security problem. Write to
ezechiel.tibiri@wave-center.org (or ezechiel.tibiri@ujkz.bf) with a description and the
steps to reproduce. You will get an answer within a few working days.

Only the latest release receives security fixes while the project is pre-1.0.
